📚 Student Management System (C#)
📖 Overview

The Student Management System is a simple C# console (or desktop/web) application that allows users to manage student records efficiently.
It demonstrates key C# concepts such as OOP (Object-Oriented Programming), Collections, and optionally Entity Framework / Database integration.

✨ Features

➕ Add a new student

✏️ Update existing student information

❌ Delete a student

📋 List all students

🔍 Search students by ID or Name

💾 Save and load data (in-memory / database / file storage depending on implementation)
